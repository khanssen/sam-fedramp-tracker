How this works

  • Source: SAM.gov's public Contract Opportunities bulk data (current file plus fiscal-year archives), downloaded weekly. data.json · notices.csv · source
  • Only the notice title and description text are searched. Requirements that appear only in attachments (PWS, SOW, RFP PDFs) are not captured, so counts are a floor.
  • Classification is keyword-based. Each opportunity gets its most specific category: FedRAMP 20x > FedRAMP with a level > FedRAMP > DoD IL > FISMA level > StateRAMP/GovRAMP > FISMA > cloud/SaaS with no framework. Mentions like “point cloud” or “cloud cover” are excluded.
  • Amendments and reposts are grouped into one opportunity by solicitation number and agency. Monthly counts use the first posted date.
  • “DFARS clause” marks notices citing DFARS 252.239-7010/7009 (DoD cloud computing). Some non-IT purchases include it as boilerplate.
  • Not affiliated with GSA, FedRAMP or SAM.gov. Always check the notice on SAM.gov.
